## 执行与计分

1. 在试用版真实登录会话中逐题重放；38～43 必须建立独立的新会话分别测试两轮，不能互相污染。记录环境、应用提交 SHA、模型名/版本、题号、完整答复、证据链接、耗时及人工判定。
2. 每题分别判定：对象/审定归属、指标数值及单位、原文或结构化状态、是否需要澄清、是否存在无依据扩展。错误归属和伪造数值为严重错误；正确拒答不能算漏查。
3. 汇总准确率、应答漏查率、跨审定错配率、应澄清未澄清率、误拦截率；按 A～E 组分层统计，不以单一总分掩盖难题。
4. 这 50 题是**定向回归集**，不是随机样本，不能由通过率外推全库准确率。后续另抽独立随机题进行泛化评估；发现数据版本变化时重新人工核定标准答案。
