# 老师原始表格问答

已授权老师目录仍以原文件为准。独立的 SQLite 单元格索引存放在科研文件卷，既不修改原 Excel，也不将材料名称自动合并进治理库。API 用户经过原有账号权限检查后，才能查询或打开来源。

模型先理解意图，再生成受校验的材料、指标、年份、老师、文件、工作表、单元格及试验条件参数。后端执行固定参数化检索，不执行模型生成的 SQL。指标来自原表表头；多层/合并表头保留测量次数、原单位及单元格坐标。记录年份优先使用指标表头和行内年份，其次使用工作表、文件名或目录标识，并明确说明依据。材料编号里的数字不直接当测量年份。

数值回答前重新核对原文件 SHA-256 和原单元格。多条记录默认产生待补充条件及选择按钮，只有明确要求全部时才逐条显示，最多30条；更多记录需要缩小范围。材料列缺表头时必须先确认，不允许跳过身份确认。缺值、原表错误以及没有保存结果的公式不被当作零，不在服务器执行公式。文件没有注明的单位不进行推断或比例换算。

回答的【原表序号】关联来源卡片，可在网页打开对应文件、切换工作表并定位单元格。来源文件更新后，历史卡片和数值查询均停止以旧索引核验，需重建索引。

## 建立或更新索引

在带原文件只读挂载和科研文件卷的 API 环境中执行：

```sh
python -m scripts.index_teacher_sources
python -m tests.smoke_teacher_sources
```

`YNAAS_TEACHER_FILES_DIR` 指向四位老师的目录，`YNAAS_TEACHER_INDEX_PATH` 指向可写的索引文件。构建先写临时文件，成功后原子替换；解析失败被记录并使构建命令退出失败，不当作无数据。

## 覆盖边界与检查

Excel/CSV/TSV可建立单元格索引。所有读取到的材料文字保留定位索引；只有能可靠识别指标表头的区域才形成可回答的指标记录。Word、图片、未识别的自由文本和基因型矩阵不自动转成表型测量事实。目录数量、识别区域数和缺值数分别记录，不能把文件已读取当成全部指标覆盖。

`test_teacher_file_query.py`检查身份、年份、重复、单位、错误、公式、来源版本及权限边界。`smoke_teacher_sources.py`核对实际老师文件并可输出独立校验样本，前端`verifyTeacherSourceIndex.cjs`用另一套读取库交叉核验原值和身份坐标。`smoke_teacher_chat_server.py`以真实登录账号运行HTTP、模型、多轮与澄清测试，仅清理它自己创建的临时测试会话。
