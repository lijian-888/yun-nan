# 云南试用版规范查询与证据层：2026-10-12 对照验证

范围：国家水稻数据中心的公开品种事实查询；不涉及 ACPs、数据写入、模型训练或五性评分规则调整。

## 判定标准

- 明确品种与审定记录时，只能给出该记录的指标；多条审定未指定时先消歧。
- 原文有疑似数值但尚未结构化时，不答“原文没有”，也不把候选值写成确认值。
- 同名来源记录不得因展示上限而悄悄丢失。
- 模型整理答案时，不仅数值本身要在证据中，数值与性状及审定记录的绑定也要正确。
- 数据库故障不能被解释成“未找到数据”。

## 固定反例与消融结果

| 关闭的机制 | 固定反例 | 关闭时 | 开启时 |
| --- | --- | --- | --- |
| 授权查询视图 | 受限 API 角色查询 D优130 福建2006直链淀粉 | 原始性状表拒绝 SELECT | 视图返回 24.1% |
| 原文候选补充 | 抚粳3号（辽粳64）辽宁1997亩产 | 错误地称无可核对亩产 | 展示 556.6、568.9 的原文候选，明确待核对 |
| 完整同名解析 | R18 株高 | 9 条来源中仅列 8 条 | 9 条全部列出，要求按来源 ID 确认 |
| 审定级数值绑定 | 将福建2006的 24.1% 写成四川2003 | 仅按数值成员校验会通过 | 按品种/审定/性状/数值绑定后拒绝 |

这些是预先固定的对抗性反例，不是全库随机抽样，也不是模型端到端准确率。对原文产量候选只做只读展示；任何后续结构化入库应另设人工核对与来源记录。

## 已运行的验证

- 只读本地数据库上的相关查询、呈现、消融及守卫测试：81 项通过。
- 不连接真实数据库的全量单元测试：249 项运行，77 项因环境条件跳过，其余通过。
- 把整个旧测试集强制接到只读真实库会导致其创建临时账号/测试表的用例报只读事务错误，因此未为测试放开写权限。

## 尚未证明的事项

- 这些固定反例不能估计 33,784 个品种上的总体召回率或原文抽取精确率。
- 数值绑定守卫覆盖本轮受控的公开单指标查询；自由格式的复杂科研报告仍需要单独评测。
- 服务器实际模型问答需在部署后运行少量真实只读冒烟用例，重点记录守卫的误拦截，而不是只看 SQL 查询通过。
- 对更广泛的缺失性状，应先抽取分层样本并人工标注，再决定是否扩大规则或增加专门的结构化流水线。

## 服务器试用版发布核验

在云南试用版独立 Compose 项目中只重建 API，镜像标签为 `ynaas-trial-api:query-evidence-20261012-r1`；原镜像 `ynaas-trial-api:70cfc78` 保留供回退。没有执行数据库迁移或修改原始业务行。

- 新镜像连接服务器真实数据库，以 API 角色运行的 44 项只读查询测试通过。
- 三条真实模型只读冒烟题通过：福建2006审定答出 24.1%；未指定审定时追问；四川2003缺值时不借用福建值。
- 另用抚粳3号辽宁1997亩产题验证原文候选在模型最终答复中仍标为待核对。
- 网关 `/api/health` 返回 HTTP 200，API 容器健康检查为 `healthy`。

上述冒烟未覆盖全部登录用户、所有品种或全部科研任务；试用期仍应记录误拦截和来源归属错误的具体问题，并纳入固定评测集。
