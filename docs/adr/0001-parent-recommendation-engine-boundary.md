# ADR-0001：亲本推荐采用确定性规则引擎，大模型不直接决策

状态：已接受  
日期：2026-10-16

## 背景

第一期亲本推荐只有国家水稻数据中心的品种、审定、描述性状、产量和系谱数据，没有可用于监督学习的基因型—表型关联数据、配合力数据或大规模真实配组后代表现。结果还需要解释硬门槛、亲缘路径、证据缺失和数据来源。

## 决策

采用分层架构：

- 大模型只解析自然语言育种目标并生成结构化条件草稿，以及把确定性结果组织为易读说明；
- 科研人员确认结构化目标后才执行；
- PostgreSQL 和规则引擎负责候选召回、硬门槛、三态证据判断、组合评分、分级和版本留存；
- 系谱算法负责三代或五代共同祖先和路径计算；
- 育种专家负责最终接受、暂缓或否决。

第一期候选源只包括国家水稻数据中心种质，院内育种材料不参与候选召回、筛选、评分或配组。

## 理由

- 当前数据不足以训练可信的后代表现预测模型；
- 硬门槛不能被生成式模型或综合高分覆盖；
- 数据缺失必须保留为未知；
- 规则、来源和系谱路径必须可复核、可测试、可审计；
- 将模型能力限制在语言理解与说明层，便于以后更换 API 或本地模型。

## 后果

- 第一阶段无需微调或训练大模型；
- 需要建设结构化条件、证据档案、系谱遍历和版本化快照；
- 规则变化可以独立于大模型升级；
- 推荐结果只能称为表型和系谱辅助推荐，不能宣称后代预测或育种成功率；
- 未来获得足量、可追溯的真实配组和后代表现后，可以新增预测模型，但必须作为独立证据层接受验证，不能替换硬门槛和专家审核。
