# 云南试用版公开品种查询：50 题回放报告

日期：2026-10-12。范围为国家水稻数据中心已入库的公开品种资料与对应审定记录，不含院内私有数据、实时网页检索或其他业务模块。标准答案与禁忌见 [50 道核定题](ricedata-query-gold-50-20261012.md)。

## 1. 数据一致性

对题集涉及的 13 个源品种，在本地库和试用服务器库分别进行只读核对：品种 13 条、审定 28 条、产量观察 63 条的内容指纹一致；按业务字段规范化后，性状事实 419 条、叙述事实 11 条、特征特性摘要 25 条的内容指纹也一致。生成 ID、元数据等非业务字段有差异，因此这**不是全库逐表一致性证明**，只支持本题集所涉业务数据一致的结论。

## 2. 执行方法

- 使用服务器数据库及其 API 角色权限，在与正式 API 同网络的隔离容器中调用真实对话规划、受控查询、模型回答及数值防串审定校验。
- 50 道题逐题独立回放；第 38～43 题各自包含两轮对话，共 56 轮模型问答。
- 保存完整模型回答、路由、证据卡片、操作状态、耗时及校验错误到 JSONL；`backend/tests/live_gold_50.py` 可在明确传入 `--run-live` 时重放，也可用 `--rescore` 对已保存结果离线重算检查分数。
- 自动检查涵盖必答数值、缺值、澄清、近似值、待核对状态、地区—数值和试验类型—数值的关联；关键答案另外人工审阅。自动分数不能替代全面的事实蕴含评估。

## 3. 结果与修复

| 阶段 | 结果 | 主要发现或处理 |
| --- | --- | --- |
| 初始镜像回放 | 38/50 通过快速筛查 | 10 道亩产题被过严的单位/年份范围校验挡下；跨轮补充“普洱、文山”丢失品种上下文；同一审定内生态区与数值的对应关系未保留。 |
| 隔离镜像定向复测 | 16/16 通过 | 修正守卫、上下文和证据提取后，原失败题及边界题均通过；对错误继承未知新品种增加反例测试。 |
| 最终隔离镜像完整回放 | **50/50 通过快速筛查，0 个守卫错误** | 逐条查看了核心证据映射；同名 R18 先澄清且不展示内部编号；缺失值不借用其他审定；原文候选明确待核对；普洱/文山、两个生态区及两类试验分别绑定正确数值。 |

最后一次评分中，“品种资料页，不是正式审定记录”被旧正则误判为未说明来源类型；只修改评分器同义表述识别后，对**同一批已保存回答**离线重算为 50/50，未为刷分重发该题。

本次本地全量单元测试 261 项，181 项执行通过、80 项因本地无集成数据库等前置条件跳过；最终隔离镜像连接服务器数据库运行 44 项相关测试，全部通过。

## 4. 尚未覆盖

回放脚本验证的是“数据库查询—对话编排—真实模型—回答守卫”的核心链路；它**没有**通过浏览器登录、HTTP 鉴权、SSE 传输及会话持久化模拟 50 个完整用户会话。真实模型存在少量上游空输出后自动重试的日志，最终题目回答成功，但应继续监测该提供方的稳定性。

数据一致性仅覆盖题集所涉 13 个源品种，未来导入或更新全库数据后应重新运行数据库差异检查及题集回归。
